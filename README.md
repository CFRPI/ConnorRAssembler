# Connor R Assembler
This is an 8 bit assembler and virtual machine written for my Computer Architecture and Assembly course. 

## How To Run

Run the main file and change the ASM_FILE_NAME variable to the name of the file you want to run. I have various test files in the root directory, part11 is a binary search tree demo. Enter five numbers to go into the tree then
a sixth number to search for and it will print 1 if it is found and zero otherwise.
